# 프로젝트 소개
중고차 매매 사이트🚘<p>
자신이 타던 차를 빠르고 합리적인 가격에 팔 수 있으며,<br>
반대로 사회초년생들을 위한 중고차 구매를 검수자들이 검토 후 판매하는 중고차 거래 사이트입니다.<br>
차량 거래의 투명성을 높이고, 사용자들이 신뢰할 수 있는 중고차를 쉽게 찾고 구매 및 판매 할 수 있도록 설계하였습니다.

## 주요 기능
### 중고차 판매
  - 판매 신청: 사용자는 차량의 상세 정보를 입력하여 판매를 신청할 수 있습니다.<br>
    이 과정에서 차량의 사진, 모델, 연식, 주행 거리 등을 등록합니다.
  - 차량 검수: 관리자와 검수자는 차량의 상태를 확인하고, 차량이 플랫폼의 기준에 맞는지 검토합니다.
  - 매입: 검수 후 차량이 승인되면, 차량이 매입되며, 사용자는 정해진 가격으로 판매를 완료합니다.
### 중고차 구매
  - 구매 예약: 사용자는 관심 있는 차량을 예약할 수 있으며, 예약을 통해 구매 의사를 표현합니다.
  - 구매 절차: 차량을 구매할 때는 직접 수령하거나 탁송 서비스를 이용할 수 있으며, 모든 거래 절차가 완료된 후 차량 구매가 확정됩니다.
### 차량용품 중고 거래
  - 1:1 채팅: 사용자는 차량용품을 거래할 때 1:1 채팅 기능을 통해 판매자와 직접 소통할 수 있습니다.
